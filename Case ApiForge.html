02

THE PROBLEM

API CLIENTS GOT HEAVY.

Mandatory accounts. Cloud sync you didn't ask for. 400 MB installs that take seconds to open. And your staging tokens living on somebody else's servers.

I wanted the thing I actually use all day: open instantly, type a URL, hit Enter, read the response — with variables that don't lie and an assistant that can write the boring glue.

03

THE BUILD

LOCAL-FIRST, TYPED EVERYWHERE.

ELECTRON, ON A DIET

No bundled runtimes beyond Chromium; lazy-loaded panels; one renderer. 24 MB installed, 92 ms to first paint.

BRIDGE PROCESS

Requests go through a local bridge so CORS never bites and large bodies stream instead of buffering in the UI.

COLLECTIONS AS FILES

Everything is JSON on disk. Commit it, diff it, share it. Import from Postman/OpenAPI in one click.

ASK CLAUDE

"Add a cursor loop and save this as a runner script" — the assistant sees the request and writes the script; you review and run.

04

FEATURE DEEP-DIVE

TYPE TOKEN. SEE WHAT RESOLVES.

Every variable is scoped (global / staging / request), typed (url, secret, int, dynamic) and previewed inline as you type. Secrets stay masked in the URL bar and never touch your clipboard by accident.

Dynamic values like $randomFrom(user_ids) resolve per request, so a collection run hits realistic data instead of the same ID 49 times.

THE IMPACT

24 MB · 92 MS · 0 ACCOUNTS.

Roughly 1/15th the install of the incumbent, opens before you finish reaching for the mouse, and nothing leaves your machine unless you ask.

WHAT I'D TELL A CLIENT

"AI built in" only works when the assistant has real context — here, the exact request on screen. Bolt-on chatbots don't; context-aware helpers do.
